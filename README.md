To run this application make sure to have these libraries and R installed:
tidyverse
shiny
leaflet
plotly
dplyr
nflfastR

to install simply type install.packages(c("tidyverse", "shiny", "leaflet", "plotly", "nflfastR")) in R
Open the R script in Rstudio and click Run App, make sure to have all files in the same directory
https://posit.co/download/rstudio-desktop <- Rstudio
https://www.r-project.org/ <- R
